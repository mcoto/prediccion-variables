# Predicción de Variables Datasets

Este repositorio contiene los conjuntos de datos utilizados en el curso de predicción de variables eléctricas y análisis de series de tiempo.

Los datasets están organizados alrededor de distintos escenarios de predicción, incluyendo:

- Demanda eléctrica
- Generación solar
- Generación eólica
- Precio spot de electricidad

A lo largo del curso se utilizan distintas versiones de los datasets para apoyar actividades relacionadas con:

- visualización de series de tiempo
- análisis exploratorio
- limpieza de datos
- predicción
- evaluación de modelos
- backtesting

El repositorio funciona como una fuente centralizada de datos para los notebooks y actividades prácticas del curso.
